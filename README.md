# 🟣 Доступ

Доступ — приложение для Windows с компактным интерфейсом, профилями подключения и уведомлениями о новых версиях.

**[Скачать последнюю версию](https://github.com/nubik1234/UnlockerDiscord_YT/releases/latest)** · **[Канал разработчика](https://t.me/NubikVibe)**

## Режимы подключения

- **Локальный** — YouTube и Discord через Zapret.
- **Гибридный** — YouTube и Telegram через VPS, Discord через Zapret. Для включения нужен личный профиль VPS от владельца сервера.

## Быстрый старт

1. Скачай архив `Dostup-…-Windows-x64.zip` из последнего релиза.
2. Распакуй архив целиком в отдельную папку и запусти `Dostup-….exe`.
3. Для гибридного режима открой **Настройки → Импорт профиля VPS**, выбери полученный JSON-файл и нажми **Включить**.
