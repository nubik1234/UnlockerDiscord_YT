# Доступ для Windows

«Доступ» — приложение для Windows с сетевыми профилями для отдельных сайтов, программ и игровых сервисов. В главном окне можно выбрать режим подключения и проверить, какие маршруты активны.

[Скачать установщик для Windows x64](https://github.com/nubik1234/UnlockerDiscord_YT/releases/download/v1.9.7/Dostup-Setup-1.9.7.exe) · [Страница приложения](https://nubik1234.github.io/UnlockerDiscord_YT/)

## Режимы подключения

- Базовый режим использует локальный сетевой движок для YouTube и Discord.
- Расширенный режим сочетает локальный сетевой движок и выборочный VPN-туннель. Он добавляет профили для Telegram, Patreon, ChatGPT, Trike Isle и отдельных игровых сервисов The Isle и The Outlast Trials.

## Установка

1. Скачай установщик и запусти его.
2. Выбери пустую папку для первой установки. Установщик распакует приложение, сетевые компоненты и обновлятор.
3. Открой «Доступ», выбери режим и нажми «Включить». Если приложение уже установлено, проверяй новые версии в настройках.
